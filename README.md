## 🙋 자기소개

대학교 3학년, 데이터베이스 수업을 계기로 Java와 웹 개발에 관심을 갖게 되었습니다.<br/>
팀 프로젝트에서 여러 도메인을 직접 설계·구현하고, 발생하는 오류를 하나씩 해결해 나가는 과정에서<br/>
큰 성취감을 얻으며 백엔드 개발자로서의 확신을 갖게 되었습니다.

실무 환경에 빠르게 적응하며 안정적인 서비스를 만드는 개발자로 성장하고 싶습니다.<br/>
유지보수성과 문서화를 중시하며, 팀원들과 적극적으로 협업합니다.

<br/>
